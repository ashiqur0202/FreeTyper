# FreeTyper

Free typing test, lessons, practice, keyboard guide, progress tracker and two typing games at [freetyper.com](https://freetyper.com). No account; progress stays in the browser (localStorage).

Next.js (App Router) + Tailwind v4. Deployed as a Docker standalone build.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build
npm run lint
```

Project notes, architecture and the current roadmap live in [`freetyper.md`](./freetyper.md).
